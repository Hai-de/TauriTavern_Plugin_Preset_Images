# Preset Prompt Images 安装说明

本文档面向插件使用者，说明如何安装、启用和验证 `Preset Prompt Images`。

## 1. 插件简介

`Preset Prompt Images` 用于给 **Chat Completion Presets（预设）** 中的提示词条目添加图片附件。

图片会作为 data URL 写入完整预设 JSON：

```text
extensions.tauritavern.presetPromptImages
```

插件会在生成请求中把对应提示词消息转成 OpenAI-compatible 多模态内容，例如：

```json
{
  "role": "user",
  "content": [
    { "type": "text", "text": "提示词文本" },
    {
      "type": "image_url",
      "image_url": {
        "url": "data:image/jpeg;base64,...",
        "detail": "auto"
      }
    }
  ]
}
```

> 注意：
>
> - 当前只支持 `marker !== true` 且 `injection_position = 0`（Relative）的提示词条目。
> - marker 条目、In-chat 注入和 Attach to existing message 上的图片会保留，但不会发送。
> - 模型是否支持图片、支持哪些 role、支持哪些格式，由预设开发者根据上游模型能力编排；本插件只负责把图片按约定放入请求。

## 2. 环境要求

安装插件本身不需要 Node.js。

如果需要从 TypeScript 源码重新构建，需要：

- Node.js 20 或更高版本
- pnpm 或 npm

## 3. 直接安装（推荐）

仓库中已经包含编译后的 `dist/index.js`，因此通常可以直接复制安装。

### 3.1 选择安装目录

把整个 `Plugin_Preset_Images` 目录复制到以下任一位置：

本地扩展目录：

```text
data/default-user/extensions/Plugin_Preset_Images
```

或全局扩展目录：

```text
data/extensions/third-party/Plugin_Preset_Images
```

安装后的目录至少应包含：

```text
Plugin_Preset_Images/
├── manifest.json
├── style.css
├── dist/
│   ├── index.js
│   └── ...
└── ...
```

### 3.2 启用插件

1. 启动或刷新 TauriTavern / SillyTavern。
2. 打开扩展设置。
3. 找到 `Preset Prompt Images` 并启用。
4. 如果面板没有立即出现，刷新一次页面。

### 3.3 验证安装

打开 `Extensions` 设置区域，应能看到：

- `Preset Prompt Images` 总开关
- 单图大小警告、单条目数量警告、单预设总大小警告

如果看不到，请检查：

- 扩展是否已启用。
- `manifest.json` 是否存在。
- `dist/index.js` 是否存在。
- 浏览器控制台是否有模块加载错误。

## 4. 从源码构建

如果你修改了 `src/` 下的 TypeScript 源码，需要重新构建 `dist/`。

在插件根目录执行：

```bash
pnpm install
pnpm build
```

没有 pnpm 时也可以使用 npm：

```bash
npm install
npm run build
```

构建输出目录为：

```text
dist/
```

`manifest.json` 始终加载：

```text
dist/index.js
```

因此修改源码后必须重新构建，否则运行时仍会使用旧版本。

## 5. 使用方式

### 5.1 给提示词条目添加图片

1. 打开 Chat Completion 预设。
2. 打开 Prompt Manager。
3. 点击一个非 marker、Relative 提示词条目的编辑按钮。
4. 在编辑弹窗底部找到 `Prompt Images`。
5. 通过以下任一方式添加图片：
   - 拖拽图片到上传区域
   - 在弹窗打开时直接粘贴图片
   - 点击上传区域选择文件
6. 编辑区会按以下结构显示：

   ```text
   [图片块]
   [提示词文本锚点]
   [图片块]
   ```

   - 拖动右侧拖动区域，可以调整图片顺序。
   - 图片拖到提示词文本锚点上方，会变为文本之前。
   - 图片拖到提示词文本锚点下方，会变为文本之后。
   - 新添加或粘贴的图片默认插入到文本之后。

7. 每张图片可设置：
   - `detail`：`auto` / `low` / `high` / `original`
   - `Replace`：替换为单个新文件，保留顺序和 detail。
   - `Remove`：删除图片。
8. 默认隐藏位置下拉框和上移/下移按钮。如果需要，可以在插件设置中打开。

### 5.2 总开关

插件设置中的总开关关闭后：

- 预设仍可使用；
- 提示词文本仍正常发送；
- 所有预设图片都不会发送。

### 5.3 预设导入导出

图片数据存储在完整预设 JSON 的：

```text
extensions.tauritavern.presetPromptImages
```

因此：

- 使用 Chat Completion 预设的完整导入/导出，可以保留图片。
- 使用 PromptManager 自己的提示词 import/export，不会携带图片，插件会给出警告。
- 没有安装本插件时，预设仍会以纯文本方式正常导入和使用。

### 5.4 多语言

插件 UI 会跟随酒馆语言设置，当前支持：

- 简体中文：`zh-cn`
- 繁体中文：`zh-tw`
- 日语：`ja-jp`
- 英语 fallback：`en`

### 5.5 导入带图片的预设

如果扩展已经启用，但插件总开关处于关闭状态，导入带图片的预设时，插件会提示是否打开总开关。

图片数据仍会保留在预设中；即使暂时不启用，也不会影响文本提示词。

## 6. 数据与安全提示

- 图片以原始 data URL 形式嵌入预设 JSON。
- 插件不提供裁剪、缩放或格式转换 UI。
- 分享预设等于分享其中的图片数据。
- 如果图片带有 EXIF / GPS / 设备信息等元数据，也会跟随 JSON 一起分享。
- 建议只导入可信来源的预设；大体积 base64 图片会显著增加 JSON 大小。

## 7. 常见问题

### 7.1 图片没有发送

请依次检查：

1. 插件扩展是否已启用。
2. 插件总开关是否打开。
3. 提示词条目是否启用了 `enabled`。
4. 提示词条目是否是 `marker !== true`。
5. 提示词条目是否是 Relative（`injection_position = 0`）。
6. 当前预设是否已正确导出/保存。

### 7.2 PromptManager 导入导出后图片丢失

这是预期行为。PromptManager 的提示词导入/导出只包含：

- `prompts`
- `prompt_order`

图片数据位于 `extensions.tauritavern.presetPromptImages`，必须使用完整 Chat Completion 预设 JSON 导入/导出。

### 7.3 没有插件时预设能用吗

可以。没有插件时，图片数据会作为未知扩展字段被忽略，文本提示词仍按原逻辑工作。
